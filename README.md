## Featured project

Compared three concepts, sized the fins with a MATLAB thermal-resistance model, and checked the result in Fusion 360.
Predicted 69.85 °C chip temperature against an 85 °C requirement. Not yet tested on hardware.
Report, plots, and STL are in [adriel-portfolio](https://github.com/adrielvent/adriel-portfolio).
